# 🎯 CareerAI — AI-Powered Career Recommendation & Guidance Platform

> Discover your ideal career path using ML-powered predictions, analyze your resume for ATS compatibility, and receive a personalized AI-generated roadmap.

🌐 **Live Demo** → [career-recommendor.vercel.app](https://career-recommendor.vercel.app)
🔗 **Backend API** → [career-recommendor.onrender.com](https://career-recommendor.onrender.com)

---

## ✨ Features

- **🎯 Career Prediction** — Answer a 10-question quiz and get ML-powered career recommendations with confidence scores
- **🗺️ AI Roadmap** — Personalized month-by-month learning roadmap generated by LLM based on your predicted career
- **📄 Resume Analyzer** — Upload your PDF resume to get ATS score, extracted skills, and AI-powered feedback
- **📊 ATS Scoring** — Rule-based ATS score evaluating skills, projects, quantification, certifications, and links
- **🤖 AI Analysis** — Strengths, weaknesses, missing skills, and improvement suggestions powered by LLM

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- CSS (Dark theme, custom components)

**Backend**
- FastAPI (Python)
- pdfplumber (PDF parsing)

**Machine Learning**
- Scikit-learn — RandomForest + GradientBoosting Ensemble
- Pandas, NumPy
- 70%+ cross-validated accuracy on synthetic dataset

**AI / LLM**
- Groq API (LLaMA based) — roadmap and resume analysis generation

**Deployment**
- Frontend → Vercel
- Backend → Render

## 🚀 Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Create a `.env` file in `/backend`:
```
api_key=your_groq_api_key
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Create a `.env` file in `/frontend`:
```
REACT_APP_API_URL=https://career-recommendor.onrender.com
```

## 🧠 ML Model

- **Algorithm** — Voting Classifier (RandomForest + GradientBoosting)
- **Dataset** — Synthetic dataset with 2700+ rows, 9 career classes
- **Accuracy** — ~71% test accuracy, ~70% cross-validated
- **Careers** — Software Developer, Web Developer, Data Scientist, AI/ML Engineer, UI/UX Designer, Electronics Engineer, Robotics Engineer, Cybersecurity Engineer, Game Developer
