🚀 AI Career Recommender & Job Guidance Platform

A full-stack AI-powered career guidance system that helps students and job seekers discover the right career path using ML predictions, LLM reasoning, skill analysis, and ATS scoring.

🔗 Frontend: AI Career Recommender (Frontend)

🧠 Features
🎯 AI Career Prediction
ML model predicts suitable career paths based on quiz responses
Provides confidence score for each recommendation
🤖 LLM Career Guidance
AI-generated explanations for career choices
Personalized roadmaps (skills + tools + learning path)
📄 Resume Analyzer
ATS-style resume scoring system
Identifies missing keywords & optimization points
💡 Strengths & Weakness Analysis
LLM evaluates user profile
Suggests improvements for better job readiness
🧪 Interactive Quiz System
Domain-based questions
Feeds ML model for prediction
🎨 Clean UI
Simple, responsive, and user-friendly interface
